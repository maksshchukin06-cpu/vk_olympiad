# Анализ результатов онлайн-олимпиады для школьников

**Очистка данных**
- убраны 37 полных дублей строк
- 19 разных написаний регионов (`Moskva`, `москва`, `мск`, `г. Москва`...) сведены к 10 реальным регионам
- найдены и убраны 73 технические сессии длительностью меньше минуты

**Разведочный анализ**
- сложность заданий (% решаемости и среднее время на каждое)
- портрет аудитории по классам, регионам, устройствам
- региональная мини-аналитика — функция, которая строит сводку по любому региону

**Проверка гипотез**
- ANOVA на разницу среднего балла между регионами. Разница оказалась статистически не значимой (p = 0.27, регион объясняет всего 0.14% различий в результатах)
- корреляция между средним временем на задание и точностью. На уровне заданий связь почти идеальная (r = 0.998), а на уровне отдельных учеников её практически нет (r = 0).
- попытка кластеризовать учеников по профилю ответов (KMeans) не сработала

## Итоги

- Три задания (из 12) решают вдвое реже среднего. Участники не бьются над ними долго, а быстро сдаются или угадывают. Вероятно, проблема в формулировке, а не в сложности содержания.
- Региональной специфики в результатах нет, поэтому делать разные региональные варианты нет надобности.
- Треть участников проходит олимпиаду со смартфона. Нужно делать упор на мобильную версию интерфейса.

## Инструменты

Python, pandas, numpy, matplotlib, seaborn, scipy (статистические тесты), scikit-learn (кластеризация).
